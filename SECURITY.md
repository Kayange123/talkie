# Security policy

## Reporting a vulnerability

Please report security issues privately using GitHub's
[Report a vulnerability](https://github.com/Kayange123/talkie/security/advisories/new) form,
not a public issue.

Include what's affected, how to reproduce it, and what an attacker could do with it. You'll get a reply on the advisory, and once the issue is fixed it can be disclosed publicly with credit to you, if you'd like.

## Supported versions

Only the latest version on the `main` branch, which is what's deployed, gets security fixes.
